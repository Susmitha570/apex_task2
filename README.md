# ApexPlanet – Task 2.Exploratory Data Analysis & Business Intelligence

## Project Overview
This project focuses on Exploratory Data Analysis (EDA), SQL-based business analysis, and dashboard development to identify meaningful patterns, trends, and business insights from data.

## Objectives
- Perform descriptive statistical analysis.
- Conduct univariate and multivariate analysis.
- Answer business questions using SQL queries.
- Identify relationships through correlation analysis.
- Develop an interactive Excel Sales Dashboard.

## Tools & Technologies
- SQL / MySQL Workbench
- Microsoft Excel
- Data Visualization
- Exploratory Data Analysis

## Project Deliverables

### 1. SQL Business Analysis
SQL queries covering filtering, aggregation, joins, and business questions.

### 2. Sales Dashboard
An Excel dashboard presenting important sales metrics and visual insights.

### 3. EDA and Correlation Analysis
A report covering data preprocessing, descriptive statistics, univariate analysis, multivariate analysis, and correlation.

## Key Learnings
- Data cleaning and preprocessing
- SQL query writing
- Exploratory data analysis
- Data visualization
- Business intelligence and reporting

## Conclusion
This project helped develop practical skills in SQL, exploratory data analysis, and business intelligence by transforming raw data into meaningful insights.
